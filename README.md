# AMR LLM Finetuning

This repository contains model fine-tuning pipelines and results for various language models on AMR (Abstract Meaning Representation) tasks.

## Contents

- `pipelines/`: Jupyter notebooks for model training
- `weights/`: Fine-tuned model weights and adapters
- `results/`: Performance plots and analysis

## Models

- DeepSeek Llama
- Gemma
- Llama
- Phi
